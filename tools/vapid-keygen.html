DxDrill push-key generator

Generate the VAPID keys used to identify DxDrill to browser push services. Keys are generated in this browser; this page does not send them to a server.

Important: Keep the private key secret. Copy it only into Supabase Edge Function secrets. Never put it in GitHub, DxDrill settings or a public message.

Store these in Supabase → Edge Functions → Secrets. If you generate another pair later, existing device subscriptions must be renewed.
